# Telegram-бот «Сімейна клініка Св. Пантелеймона»

Самодостатній бот для запису + бекенд для форми сайту. Працює на Cloudflare Pages Functions (безкоштовно).

## Можливості (v1)

1. **Запис через бота** — діалог: послуга → імʼя → телефон (кнопка «Поділитися номером») → день → коментар → підтвердження → заявка в приватну групу.
2. **Інфо-меню** — графік з індикатором «відчинено зараз» (Europe/Kyiv), послуги, безкоштовне за декларацією, адреса з геоточкою, Google-відгуки, телефон.
3. **Міст «питання лікарю»** — вільний текст пацієнта пересилається в групу; відповідь реплаєм у групі доставляється пацієнту від імені клініки.
4. **Кнопка «✅ Опрацьовано»** під заявками в групі + автоповідомлення пацієнту.
5. **Форма сайту** шле на той самий бекенд (`POST /api/submit`) → та сама група.

## Архітектура

```
Пацієнт ↔ Бот (webhook /api/telegram) ─┐
                                        ├→ Приватна група «Заявки» (клієнтка + Ігор)
Форма сайту → POST /api/submit ────────┘
```

- `functions/api/telegram.js` — webhook бота (діалоги, меню, міст, callback-кнопки)
- `functions/api/submit.js` — приймає форму сайту
- `functions/_lib/` — спільне: Telegram API, тексти, валідація, графік роботи
- **KV** (binding `KV`): сесії діалогів `sess:<chat_id>` (TTL 1 год), мапа моста `bridge:<group_msg_id>` → chat_id пацієнта (TTL 7 днів)
- Секрети: `TG_BOT_TOKEN`, `TG_CHAT_ID` (id групи), `TG_WEBHOOK_SECRET`; `DRY_RUN=1` для локальних тестів без Telegram

## Налаштування (одноразово)

### 1. Створити бота (робить Ігор або клієнтка зі свого Telegram)
1. Написати @BotFather → `/newbot`
2. Name: `Сімейна клініка Св. Пантелеймона`
3. Username: наприклад `sv_panteleimon_bot`
4. Зберегти **token** (виглядає як `1234567:AA...`)
5. `/setdescription` — «Запис на прийом, графік, адреса та відповіді на питання»
6. У @BotFather → `/mybots` → бот → Bot Settings → **Group Privacy → OFF** (щоб бот бачив реплаї в групі для моста)

### 2. Група для заявок
1. Створити приватну групу «Св. Пантелеймон — заявки»
2. Додати бота і клієнтку
3. Дізнатися chat_id групи: написати щось у групу, потім
   `curl "https://api.telegram.org/bot<TOKEN>/getUpdates"` → `chat.id` (відʼємне число, типу `-100…`)

### 3. Cloudflare Pages
1. Проєкт Pages з цього репозиторію (build: немає, output: `/`)
2. Settings → Environment variables: `TG_BOT_TOKEN`, `TG_CHAT_ID`, `TG_WEBHOOK_SECRET` (випадковий рядок)
3. Settings → Functions → KV namespace binding: `KV`
4. Поставити webhook:
   `curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<site>/api/telegram&secret_token=<TG_WEBHOOK_SECRET>"`

### 4. Сайт
- Плаваюча Telegram-кнопка: замінити `https://t.me/your_clinic_bot` на реальний нік бота.

## Локальна розробка

```bash
cp .dev.vars.example .dev.vars   # вписати тестові значення (або DRY_RUN=1)
npx wrangler pages dev .          # localhost:8788, /api/* працюють
```

Смоук-тест логіки без мережі: `node tests/bot-smoke.mjs` (DRY_RUN, мокнутий KV).

## Потік запису (стан у KV)

`idle → svc → name → phone → day → comment → confirm → done`

- Телефон: кнопка `request_contact` або текст (валідація +380)
- День: «Сьогодні / Завтра / Інший день (текстом)»
- Поза графіком — бот попереджає, що передзвонять у робочий час
- Скасувати будь-коли: /cancel або кнопка «✖️ Скасувати»
